FireWatch Sentinel

Detecting vegetation stress before smoke and flames appear.

FireWatch Sentinel is a cost-effective wildfire-risk monitoring prototype designed to identify local areas of stressed vegetation before visible signs of smoke or fire appear. It combines environmental conditions, vegetation vibration and acoustic signals, soil conditions, and airborne-particle measurements to help land managers and safety teams identify areas that may need inspection.

Our Mission

Help land managers, utility operators, campuses, parks, forestry teams, and emergency-response organizations identify vegetation stress and changing environmental conditions before they develop into a serious wildfire threat.

FireWatch Sentinel is intended to support human decision-making, not replace firefighters, researchers, or environmental professionals. Every alert the system produces is a recommendation for a trained person to review — never an automatic action.

🛈 Human-in-the-loop by design — the system recommends inspection, it never dispatches, evacuates, or decides on its own.

What Makes FireWatch Different

Most tools watch for fire. We watch for the conditions that lead to one.

Cameras, satellites, and smoke sensors are strong at regional risk modeling and active-fire detection. FireWatch Sentinel is built to fill the layer underneath: localized, pre-ignition vegetation stress.

Traditional Approach

Detect smoke or fire.

Regional models, satellite thermal anomalies, cameras, and gas sensors are strongest once combustion or smoldering has already begun.

FireWatch Approach

Identify stressed vegetation and dangerous conditions earlier.

Acoustic/vibration signals, soil moisture, and environmental readings flag zones worth a human inspection — before visible smoke or flame.

Pre-ignition vegetation stress

Focused on the condition of vegetation before ignition, not after.

Tree-level, localized monitoring

Watches individual trees or small zones, not just broad regions.

Multiple sensor signals

Combines readings rather than relying on any single measurement.

Low-power operation

Designed to run for extended periods with minimal energy draw.

Solar-powered field deployment

Built around a solar panel and rechargeable battery for remote sites.

Remote communication

Plans for LoRa and gateway relay so isolated sites can report in.

Human review before action

Every alert is a recommendation, reviewed by a trained person.

Affordable prototype components

Built from accessible, budget-conscious hardware.

Expandable sensor nodes

Additional nodes can be added as coverage needs grow.

FireWatch Sentinel does not claim to predict or prevent every wildfire. It is a risk-monitoring and inspection-support system — a proof of concept that tests whether acoustic and environmental signals can improve local wildfire-risk awareness, not a certified fire-prediction product.

// FireWatch Sentinel — Serial Monitor (simulated)
View simulated ESP32 code 
void loop() {
  tempF   = alpha*temp  + (1-alpha)*tempF;      // filter noise
  humF    = alpha*hum   + (1-alpha)*humF;
  soilF   = alpha*soilMoisture + (1-alpha)*soilF;
  pm25F   = alpha*pm25  + (1-alpha)*pm25F;
  vibF    = alpha*vibration + (1-alpha)*vibF;

  riskScore  = mapRange(tempF, 20, 50, 0, 25);   // heat
  riskScore += mapRange(humF, 100, 10, 0, 25);   // dryness
  riskScore += mapRange(vibF, 0, 100, 0, 20);    // stress signal
  riskScore += mapRange(pm25F, 0, 250, 0, 20);   // smoke/dust
  riskScore += mapRange(soilF, 100, 0, 0, 10);   // dry soil

  riskLevel = classify(riskScore);  // GREEN / YELLOW / ORANGE / RED
  sendPacket(jsonBuffer);           // LoRa / Wi-Fi transmission
}
